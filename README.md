
# PiCar-X V4 + Raspberry Pi 5

**Open Robotics & Physical AI Engineering Project**

An open-ended engineering project built around the SunFounder PiCar-X V4 and a planned Raspberry Pi 5.

## Mission

Build, understand, test, measure, document, and continuously improve a modular robotics platform — progressing from basic assembly and Python programming to autonomous navigation, computer vision, embedded systems, and Physical AI.

## Engineering Pillars

1. **GitHub Engineering Journal** — Version control, documentation, experiments, and reproducibility.
2. **Telemetry** — System monitoring, measurements, and performance analysis.
3. **Safety Controller** — Motion limits, command validation, watchdogs, and fail-safe behavior.
4. **Hybrid AI** — Raspberry Pi 5 for local control; external PC/LLM/VLM for demanding computation.
5. **Raspberry Pi Pico 2 W** — Future embedded and real-time extensions.

All five pillars are approved development directions, not claims of completed implementation.

## Development Roadmap

The project follows milestones **M0–M13+**, covering hardware identification, assembly, Linux, Python, control systems, sensors, autonomy, AI, and ongoing research.
